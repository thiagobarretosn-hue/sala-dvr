Sala DVR rclone

Backup doméstico das gravações das câmeras de casa no Google Drive do próprio dono.

O que é

O Sala DVR rclone é um projeto pessoal, sem fins comerciais, que roda num único computador doméstico. As câmeras da casa gravam no computador, e o programa de código aberto rclone usa este aplicativo OAuth para enviar as gravações para uma pasta no Google Drive do dono da casa.

Como usa o Google Drive

  • Pede apenas o escopo drive.file: acesso somente aos arquivos que o próprio aplicativo criou. Ele não lê, não lista e não altera nenhum outro arquivo do Drive.
  • Envia os vídeos para a pasta "Cameras Sala" e apaga dessa pasta os vídeos com mais de 7 dias.
  • Não há outros usuários: o aplicativo é usado só pela conta do dono do projeto.

Política de privacidade

English

Sala DVR rclone is a personal, non-commercial home project running on a single computer. It lets the open-source tool rclone upload the home security camera recordings to a folder in the owner's own Google Drive. It requests only the drive.file scope (files created by the app itself), deletes recordings older than 7 days from that folder, and is used only by the project owner's account. See the privacy policy.
