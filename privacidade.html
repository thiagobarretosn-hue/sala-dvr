Política de privacidade — Sala DVR rclone

Última atualização: 18 de novembro de 2026

1. Quem usa

O Sala DVR rclone é um projeto pessoal e doméstico. O único usuário é o dono do projeto, com a própria conta Google. O aplicativo não é oferecido ao público.

2. Dados do Google acessados

O aplicativo pede apenas o escopo https://www.googleapis.com/auth/drive.file. Com ele, só tem acesso aos arquivos e pastas que ele mesmo criou no Google Drive. Não lê, não lista nem altera outros arquivos da conta, e não acessa e-mail, contatos ou qualquer outro dado do Google.

3. Como os dados são usados

  • Os vídeos das câmeras da casa são enviados para a pasta "Cameras Sala" no Drive do dono.
  • Os vídeos dessa pasta com mais de 7 dias são apagados automaticamente.
  • O token de acesso fica guardado só no computador doméstico onde o programa roda.

4. Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade, análise ou treinamento de modelos de IA. Não há servidor intermediário: o envio vai direto do computador doméstico para o Google Drive.

5. Uso Limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Privacy policy — Sala DVR rclone

Last updated: November 18, 2026

Users. Sala DVR rclone is a personal home project. Its only user is the project owner, with their own Google account. It is not offered to the public.

Google data accessed. Only the drive.file scope: access is limited to files and folders the app itself created. It does not read, list or modify any other Drive file, and does not access email, contacts or any other Google data.

Use. Home camera recordings are uploaded to the "Cameras Sala" folder in the owner's Drive, and recordings older than 7 days are deleted from that folder. The access token is stored only on the home computer running the program.

Sharing. No data is sold, shared or transferred to third parties, or used for advertising, analytics or AI model training. There is no intermediate server.

Limited Use. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. myaccount.google.com/permissions.

Contact. github.com/thiagobarretosn-hue/sala-dvr/issues
